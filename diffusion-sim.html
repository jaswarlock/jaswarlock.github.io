How Crank-Nicolson Works

Step 1 — Discretize Domain

Divide [0, L] into N–1 equal intervals. Interior nodes i = 1…N–2 are solved; boundary nodes i = 0 and i = N–1 hold fixed Dirichlet BCs throughout.

Δx = L / (N-1) x_i = i · Δx

Code: dx = L/(N-1), array C[] init to 0, then C[0]=cL, C[N-1]=cR.

Step 2 — Fourier Number

The Fourier number r governs how diffusion spreads per time step. Explicit methods blow up for r > 0.5. CN has no such restriction — it's unconditionally stable for all r.

r = D · Δt / Δx²

Code: r = D*dt/(dx*dx). Displayed live so you can push r above 0.5 and observe CN staying stable.

Step 3 — Build LHS Matrix A

The implicit half of CN (at time n+1) gives a tridiagonal system for (N-2) interior unknowns. Every diagonal = 1+r, every off-diagonal = −r/2.

diag(A) = 1 + r off-diag = −r/2

Stored as scalar constants aMain = 1+r, aOff = -r/2 — no matrix allocation needed.

Step 4 — Build RHS Vector b

The explicit half (time n) forms the right-hand side. Boundary-adjacent nodes need both the explicit AND implicit BC contributions:

b[i] = r2·C[i-1]ⁿ + (1-r)·C[i]ⁿ + r2·C[i+1]ⁿ b[0] += r2 · cL ← implicit BC correction b[n-1] += r2 · cR ← implicit BC correction

Missing the implicit correction was the original bug — it caused the profile to stagnate near the boundaries.

Step 5 — Thomas Algorithm

Solves the tridiagonal system Ax = b in O(N) time. Far faster than dense Gaussian elimination. Two passes: forward sweep eliminates lower diagonal, back substitution recovers solution.

// Forward sweep w = aOff / m[i-1] m[i] -= w · aOff b[i] -= w · b[i-1] // Back substitution x[i] = (b[i] - aOff·x[i+1]) / m[i]

Step 6 — Steady State

When max concentration change per step falls below 1×10⁻⁹, the profile has converged to the analytical linear steady state. Watch the cyan curve meet the orange dashed target.

C_ss(x) = C_L + (C_R − C_L) · x/L

In battery context: this is the equilibrium Li⁺ distribution across the electrolyte layer under fixed electrode concentrations.
